# 个股多因子量化评分 V1.0 设计（stock-scoring）

- 日期：2026-09-26
- 状态：已批准（设计评审通过，试跑验证完成）
- 依据：《A股多因子量化选股评分规则 V1.0.docx》+ 本设计中的适配决议
- 前置验证：2026-09-25/26 三轮试跑（V2 修正跑、国信数据交叉验证、V1.0 规则全池试跑）

## 1. 定位与目标

在定投信号台的**股票页**新增量化初筛层（不另起炉灶、不改基金页逻辑）：

1. 精选池 **Top10 买入建议**区块（仅展示，附免责声明）；
2. **持仓股票卡片评分胶囊**，展开显示四因子明细与风险标记；
3. 评分输出为"横截面相对位置"，不产生机械买卖指令。

评分哲学遵循规则文档 §24：寻找四因子风险收益比合理的股票，并显式区分
①四因子共振 / ②基本面强趋势弱 / ③低估值基本面弱 / ④高成长极高估值 四类形态。

## 3. 数据层

### 3.1 主数据源：国信智能选股（gs-smart-stock-picking）

每晚 **2 次全池调用**（实测单次返回 5222 行，无实质行数上限）：

- **Q1 财务因子**：`全部沪深A股的加权净资产收益率、归属母公司股东的净利润同比增长率、扣非净利润同比增长率、营业总收入同比增长率、销售毛利率、资产负债率、市盈率PE、所属同花顺行业`
  - 返回列：ROE（**注意：默认措辞返回"摊薄"口径，生产查询措辞需显式锁定"加权"**）、PE(TTM)、同花顺三级行业、股票市场类型
- **Q2 动量因子**：`全部沪深A股的60日涨跌幅、20日涨跌幅、最新收盘价、20日均价、60日均价、所属同花顺行业`
  - 区间涨跌幅/成交均价列名内嵌日期窗口，视为 MA 近似（已与 past_hq 逐只 MA 互验：26.74 vs 26.66、27.63 vs 27.67）

辅助（小批量）：
- `past_hq`：仅为 Top10+持仓生成明细 K 线快照（≤13 次/晚）；
- 三表接口 `a_income/a_balance count=4`：仅周期股 3 年校验（≤13 只 ×2 次）；
- 商誉/质押/审计三项：实施时探测智能选股列是否可批量给出（如"商誉占净资产比值"）；给不了则该 flag 留空并在本文档追加降级记录。

### 3.2 精选池（候选范围）

现有 1165 只 A 股（沪深300+中证A500+科创综指+创业板指+北证50，东财 `RPT_INDEX_COMPONENT` 季度刷新）+ 北证50 借国信数据补齐。池清单存 `settings.pool_codes`，季度人工确认刷新。

## 4. 评分引擎（TS 纯函数）

```
Quality  = 50%·ROE行业百分位 + 50%·毛利率行业百分位        # 金融/缺失 → NA重归一
Growth   = 35%·扣非增速 + 15%·归母增速 + 50%·营收增速      # 均为行业百分位
Value    = 50%·PE逆百分位 + 50%·PEG逆百分位               # PEG无效→PE单指标；亏损→维度NA
Momentum = 50%·[50%·60日涨幅行业百分位 + 50%·Price/MA20行业百分位]
         + 50%·绝对趋势{0,33,67,100}
Final    = 30·Q + 30·G + 20·V + 20·M                      # 任一维度NA→其余按原权重比例归一
```

- 不评分线：有效权重覆盖 <40% → "数据不足，不评分"；
- 全部中间量（各百分位、原始指标、PEG值、行业样本数 N）随分数落表，前端展开明细零额外调用；
- 输出附 §23 全字段：行业排名 X/N、全市场分位、池内排名、flags、warnings、数据完整度、主要加分/扣分项（各因子百分位的 top/bottom）。

## 5. 执行与存储

- **新 Edge Function `stock-score`**（与 daily-update 分离，故障隔离）：每晚定时触发；
- 流程：GS×2 → 合并校验（行数<4000 视为上游异常，保留旧批次）→ 评分 → 批量写 `stock_score`（batch_date 批次制，先写新批后删旧批）→ Top10+持仓做 past_hq/三表增强；
- **表 `stock_score`**：`code, name, ths_l1/l2/l3, batch_date, quality, growth, value, momentum, final, ind_rank, ind_n, market_pctl, in_pool, cov, pe, peg, roe, flags jsonb, warnings jsonb, extras jsonb`；RLS 只读 anon；
- GS 失败重试 2 次；当日无新批次时前端显示旧批次 + "评分数据截至 {batch_date}" 陈旧提示。

## 6. 前端（股票页）

1. **Top10 区块**（fund-head 下方新 card）：名称/代码、终分+星级、四因子迷你横条、行业排名、池内/市场分位、flag 徽章；点击展开建仓建议（首笔30% + 回调5%加30% + 回调10%加40%）与免责脚注（评分≠买入）；
2. **持仓胶囊**：`62.9分 · 行业50/238 · ★★` 样式并入现有 signal-strip；点击展开四因子明细 + 加分/扣分项 + 周期/风控警示；
3. 区块头显示批次时间与财务报告期。

## 7. 测试方案

- **单测（纯函数）**：百分位/并列处理、P1/P99 截尾、PEG 有效性五判据、维度/子指标双层 NA 重归一、绝对趋势三条件、行业回退（≥20 边界）、ST 过滤、覆盖<40% 不评分；
- **黄金样本断言**（对 2026-09-26 试跑结果）：潍柴 M≈15 / Q≈80（基本面强趋势弱型）、亚虹医药 Value=NA 三维重归一、宁波银行 ROE 单腿、荣昌生物 PEG=NA + 周期警示触发、奥飞娱乐 L1 回退；
- **集成**：部署前本地完整跑 Function 一次，Top20 与试跑名单 diff <5 名（数据日允许微差）；浏览器实测胶囊与明细展开。

## 8. 试跑结论摘要（设计依据）

全 A 5021 只单次试跑：中位 49.3、≥80 分 63 只；池内 Top10 行业离散且均为行业头部；持仓三只（海康 64.4/82 分位、潍柴 62.5/78 分位、三一 54.1/60 分位）均为"质量成长估值中上 + 动量 15-20"的②型形态，与 MA 空头排列事实自洽；财务字段与东财 F10、国信三表三方互验一致。

## 9. 遗留与边界

- 加权 ROE 查询措辞待生产联调锁定（试跑拿到的为摊薄口径，横截面排序影响极小但口径需记录）；
- 商誉/质押/审计 flags 的可得性实施时探测，允许留空；
- 恒生科技不进引擎；权重 30/30/20/20 未经回测不得调整（§22）。
