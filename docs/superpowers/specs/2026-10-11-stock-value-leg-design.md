# 个股价值腿 VQ 设计（stock-value，巴菲特式质量价值 · 并行于现有四因子）

- 日期：2026-10-11
- 状态：待评审
- 定位：与现有 `stock-score`（V1.1 四因子 Q30/G30/V20/M20）**并列的第二评分体系**。独立 Edge Function、独立表、独立 cron；**不修改现有任何规则与权重**（用户裁定）
- 前置探针：2026-10-11 六轮国信接口实调（11 次调用）。§2 全部为实测结论，非推测
- 本轮批准要点：FCF 为主股息 5% / 价值腿走硬否决 / 先出文档再开工 / 卖出侧仅并入 5pp 换仓门槛（§7.3）

## 1. 为什么要有第二套分数

现有 V1.1 是**质量+成长导向的横截面相对排名**：权重 Q30/G30/V20/M20，动量占 20%，价值仅 20% 且只有 PE+PEG。它的产出是"这只股票在自己行业里排第几"，天然回答不了巴菲特式的那个问题——**"按它自己的常态盈利能力，这个价格值不值得拥有？"**

横截面排名有个结构性缺陷：一只 60 倍 PE 的半导体股，在半导体组内可以排到"便宜"（行业内相对分位），但它并不便宜。所以价值腿必须**两层分工**：

| 层 | 用什么 | 回答什么 | 可否被行业漂移污染 |
|---|---|---|---|
| **门禁层** | 绝对阈值（owner yield、ROIC 水平与持续性） | 值不值得拥有（买入门槛） | 否——绝对量与十年国债比，与同行无关 |
| **排序层** | 四维百分位加权合成 VQ | 在合格者中谁更靠前，以及**与主分的分歧** | 是——故只用于排序，不用于准入门槛 |

产出物不是"又一个排行榜"，而是**分歧榜**（§7）：VQ 高而主分低 = 被动量错杀的价值；VQ 低而主分高 = 动量堆出来的贵货。这才是"扩充策略"的兑现处，也是前视验证要盯的对象。

## 4. 门禁层：owner yield 与绝对阈值（价值判断，与行业无关）

```
normalized_roe_base  = 净资产(货币资金与带息债务近似投入资本，见 §4.1)
owner_yield_cash     = fcff / 总市值                       # 当期真金白银收益率
owner_yield_norm     = roic_med × 投入资本 / 总市值          # 常态盈利能力收益率（防周期高峰）
owner_yield          = min(owner_yield_cash, owner_yield_norm)   # 取小：保守，同时惩罚烧钱与虚高
margin_of_safety     = owner_yield − cn10y                  # 相对十年国债的超额回报（pp）
```

**门禁判据（全部满足才有资格进入排序层）**：

| 判据 | 阈值 | 含义 |
|---|---|---|
| `owner_yield > 0` | 硬 | 现金创造为正（烧钱公司直接出局） |
| `roic_med ≥ 8%` | 硬 | 常态资本回报高于机会成本下限；无护城河证据者出局 |
| `margin_of_safety ≥ 2pp` | 软门禁 | 低于此值标 `too_rich`：**质量达标但不值得买**，不产生卖出指令 |

**硬否决（一票制，与分数无关，页面红标）**——本轮批准"价值腿用硬否决"，与主引擎"风控只标记不扣分"（V1.0 决策 1）**刻意不同**：扣分表达"差多少"，否决表达"能不能碰"。

1. `PB < 0` 或 净资产为负 → 资不抵债
2. `商誉/净资产 > 50%` → 不可逆爆雷风险（空值按 0 处理）
3. 近 2 期 `fcff < 0` 且 `带息债务/货币资金 > 2` → 烧钱加杠杆（价值陷阱标准形态）
4. `roic_cur` 与 `roic_med` 双双 `< 8%` → 无护城河证据
   - 金融股（`isFin`）此判据改用 `ROE(扣非加权)` 对标，避免整类被误杀；`roic` 对金融股天然 NA（P-1）
   - **`isFin` 的判定源（用户裁定，2026-10-12）**：取自 GS 市场成员列（`gs_value.ts:199`，不被 `全部A股(非金融)`  universe 收录者即金融），**不是** `ths_l1 ∈ {银行,非银金融,证券,保险}`。两者是不同集合：首跑 5025 行里有 18 只 ths_l1=非银金融（含 `300059 东方财富`、`000987 越秀资本`、`600517 国网英大`、`603300 海南华铁`）被 GS 归入非金融，故按 ROIC 判护城河且 `roic_cur`/`roic_med` 双 <8 → 否决成立。后果已知并接受：券商/金控平台的 ROIC 因客户保证金与自营杠杆而结构性偏低，这一路径可能把它们挡在名单外。**维持现状**（上线前夜不改判定集合），如需扩集合并只动 `isFin` 一处，代价是重跑批并重看 A 级/`tier` 分布。

否决者**仍落库**（`vetoed` 记原因数组），前视验证需要知道"被排除的那批后来怎么样了"。

### 4.1 投入资本近似

GS 宽表无"净资产/股东权益"直接列（P-1 未验到），投入资本用 `货币资金 + 带息债务` 近似。此为**已知粗糙近似**，落地时须用 3 只样本对照国信三表接口的真实股东权益，误差 >25% 则改为三表接口单只补取（仅 Top 榜，≤13 只/晚）。近似状态记入 `value_extras.ic_approx=true`，前视复盘时知情。

**2026-10-13 校准实测 + 改道条件修订（决议 15，用户裁定「保留近似，但把保守性证据写成豁免条件」）**：

- 校准实跑用 **10 只**（超原文要求的 3 只），真值取自 GS 三表接口 `balanceSheet` 的 `sEWithoutMI` / `totalShareholderEquity`（报告期 2025-12-31，字段名由探针打印的真实响应树形确认，非猜测）。中位误差 **20.48%（归母口径）/ 25.05%（股东权益合计口径）**，逐只散布 2.4%–74.6%。原文未消歧「股东权益」取哪个口径，两个合理读数恰跨在 25% 线上——**中位数本身不足以判**，看散布才看得出近似在个体层面不可靠。
- 原文 remedy「改为三表接口单只补取（仅 Top 榜，≤13 只/晚）」经实测**不可执行**：本批受 IC 影响的行有 3831 只（`norm_yield` 非空），逐只补取约 2.5 小时，远超夜间窗口。
- 但逐只传导分析证明该近似**只向保守方向偏**：`oy = min(cashY, normY)` 的取小把误差夹住——10 只样本里 **5 只 Δoy = 0**（近似完全不参与结果），其余 5 只换真值后 owner_yield **只会被抬高** +0.30 ~ +7.18pp，**无一例被算高**。净效果是榜单偏小（漏放），不是放进不该进榜的公司。
- ⇒ **改道触发条件修订为**：中位误差 >25% **且**误差存在向「多选」方向传导的实例，才必须换真值口径；仅越线而传导保守 → 允许保留近似，继续以 `extras.ic_approx=true` 知情。本轮按此条判定为**豁免保留**。
- 顺带记录一条被实测推翻的前提，供后续重议（本轮不做）：净资产可由 `总市值 / 市净率` **零成本反推**（两列都已在 V_Q4 批量响应里，10 只对账中位误差 **1.93%**、最大 17.34%）——即本节「GS 宽表无净资产直接列（P-1 未验到）」不成立。但换上该真值会让 **1399 行**新过 `MOS_GATE=2pp`（仅 2 行掉出），qualified 从 88 只（1.75%）涨到约 28%，说明**这条粗糙近似当前正在替门禁承担筛选强度**；换真值必须与 MOS 门禁重设计同批做，且前视复盘的可比起点要重置。

## 5. 排序层：四维百分位合成 VQ（批准权重）

### 5.1 权重表（合计 100，缺腿 renorm，沿用 `engine.ts` 双层 NA 纪律）

```
VQ = 35·资本回报护城河 + 25·现金回报 + 25·安全边际 + 15·财务稳健
```

| 维度 | 子指标（权重） | 口径 |
|---|---|---|
| 资本回报护城河 35 | `roic_cur` 组内分位 12 / `roic_med`（3 年中位）13 / `roic_min3`（3 年最差年）10 | 用"最差年"而非标准差：护城河的定义是**穿越周期不掉**，单年异常不该被平滑掉 |
| 现金回报 25 | `fcf_yield = fcff/总市值` 20 / `div_yield_5y` 5 | 按批准：owner earnings 核心是"能产生多少现金"，不是"发没发出来"，故股息只给 5%；不分红记 0 参与排名（P-6） |
| 安全边际 25 | `E/P = 1/pe`（pe>0）10 / `正常化盈利收益率 = roic_med×净资产/总市值` 10 / `B/M = 1/pb`（pb>0）5 | 三者非独立（B/M 与正常化盈利共享净资产项），权重已压低 B/M；用常态盈利而非当期高峰，是防周期陷阱的关键一招 |
| 财务稳健 15 | `净现金/市值 = (货币资金−带息债务)/总市值` 8 / `有息负债率`逆分位 4 / `商誉/净资产`逆分位 3 | 金融股 `有息负债率` 腿 NA → renorm |

### 5.2 边界处理

- `PB≤0` / `PE≤0`：经济意义无效 → NA（不进门禁分母，但 PB<0 已触发否决）
- `商誉/净资产` 空值 → **0**（无商誉是好事，不作 NA）
- `股息率` 空值 → **0**（不分红是真实负面信息，不作 NA）
- `roic` 三年不足 2 期 → 该两腿 NA，VQ 靠当期 ROIC + 现金 + 估值 + 稳健支撑，`vcov` 自然下降

## 6. 置信度分级（照搬 V1.1 §4.7 纪律）

三年 ROIC 齐备率仅 63%（P-2），意味着大量股票的 VQ 是"缺腿 renorm 出来的"，**不能与满腿者直接比大小**。故：

| 级 | 条件 |
|---|---|
| A | 三年 ROIC 齐备 + 四维度均 ≥1 腿有效 + 无否决 |
| B | 缺 1 维度，或 `roic` 仅 1-2 期，或带任一个股级 flag（界定见下注） |
| C | 缺 ≥2 维度，或分组退化到 MARKET 且组内 <20，或 `vcov < 0.6` |

**「任一 flag」的边界（用户裁定①，2026-10-12，首跑 5025 行实数据后）**：本表原写「带任一 flag」，而 `flags` 里混了两类不同口径的东西。**总体级** flag 说的是数据源的回填形态，不是这一只票的毛病：`gw_empty_as_zero`（GS 对无商誉公司回空 → 落库按 0 参与）、`pe_na_nonpositive`（亏损股 PE 非正）、`pb_na_nonpositive`（净资产为负者 PB 非正）——首跑它们分别盖 2522 / 1204 / 0 行，三类合计盖 89% 行，于是「带任一 flag → 不得 A」把 spec §10 要求的 A 级占比 ≥40% 数学锁死在实测 10.6%。故三者**不再参与置信度，但仍原样落库留痕**（前视与页面都看得到）；它们的数值后果本来已在别处付过：ep/bm 腿置 NA 拉低 `vcov`，商誉按 0 进百分位。仍在本行降级的**个股级** flag：`roic_3y_incomplete`（即本表「`roic` 仅 1-2 期」）、`rf_fallback`（计价锚退化）、`veto:*`。先例：`ic_approx` 因同一理由不进 `flags`（§4.1）。实现落点：`value_engine.ts` 的 `CONFIDENCE_FLAGS` / `flagsDepressConfidence`。

`vcov < 0.6` → **不产出 VQ**（`final=null`），只落原始指标。分歧榜（§7）只从 A 级取，避免"缺数据造成的便宜"混进结论。

## 7. 产出与前端

1. **价值 Top10**：`tier=qualified` 且 A 级，按 VQ 降序；列：VQ、`owner_yield`、`margin_of_safety`、`roic_med`、池内/市场分位。（**否决标记不在本卡**——本卡先 `filter(tier==='qualified')`，而否决行 `tier==='vetoed'`，列在此逻辑上恒空；否决的可见性由 §7.4 的持仓卡胶囊「价值 硬否决 ⛔」承载。见 §11 第 11 条。）
2. **分歧榜**（本设计的核心交付）：
   - 被错杀：VQ 池内前 20 分位 × V1.1 主分后 50 分位
   - 虚高：VQ 后 50 分位 × 主分前 20 分位
   - 每个样本附一句归因（例：`VQ 78(P8) / 主分 54(P22) — ROIC 中位 19% 但 60 日涨幅组内 P9`）
3. **换仓建议行 `swap_suggest`（废弃版卖出模块 A 的唯一保留项）**：当某**未持有的合格标的** X 的 `margin_of_safety` 比某**当前持仓** Y 高出 **≥5pp** 时，在 Y 的持仓卡上给一行提示，注明错价优势 delta。**它只多一行显示，不改写任何现有信号**——`too_rich` 永不构成减仓，换仓与止盈的行动权仍归 `profitTiers` 阶梯与主信号横幅仲裁（§9.6）。这是纯机会成本逻辑，与止损无关。`rf_fallback=true` 时若两侧 margin 口径不一致（一侧绝对下限、一侧动态），本建议**整体静默不产出**，不混用口径。
4. **持仓卡**：并入现有 signal-strip 一颗胶囊 `价值 78 · 池内 P8`，展开显示四维度横条 + `owner_yield` 明细 + 门禁判定过程
5. 固定免责脚注：价值分是"值不值"的判断，不等于买卖指令；两套分数不可互相替代
6. **长期趋势角标**（2026-10-13 用户裁定新增，2026-10-14 改口径；**纯展示，不进分数/不进排序/不进门禁**）：
   - 只给本卡 Top10 逐行补标签；取数走前端 JSONP 直连东财月线（`klt=103 fqt=2 lmt=10000`），**不进 cron、不落库、不写任何表**，外网请求天然封顶 10 次/刷新
   - 窗口：**上市至今全部月线**（实测最久 390 根一次到位）；上市不足 **24 个月**、长期停牌、取数失败一律判 NA（`长期—`），绝不用短窗凑一个能渲染的数
   - 判据四腿（全过才 `长期↑稳升`）：上市至今年化 >0 · 月线 log 价 OLS **R² ≥ 0.6** · 现价 > 近 24 月线均值 · **年化 ≥ 0.15 × |上市至今最深回撤|**；`年化 ≤0` 或（破 24 月线且近 24 月也在跌）→ `长期↓破位`；其余 `长期↔纠缠`
   - 披露：位置项窗口仍为近 24 月线（判"现在破没破"，与长期方向是两回事）；最深回撤已进判据，故**必须不依赖 hover 可见**（内联小字 `回撤 -X%`）；后复权口径下绝对价不是行情价 ⇒ title **只报比率与样本月数，不报任何绝对价**
   - 命名必须与窗口同名：窗口真是上市至今，才配得上「长期」二字（旧「24月↑稳升」「慢牛/纠缠」均废）
   - **as-of 口径（决议 24）**：东财当月未收盘根**计入**样本，标签是「当日价口径」；处在零附近的边界股会随价在 `长期↔纠缠` / `长期↓破位` 之间移动，这是「现价 vs 24月线」与「近24月斜率」两条腿的定义使然，**不加死区、不改窗口**
   - **破位拆腿归因（决议 25）**：`长期↓破位` 角标后内联一颗 `.trend-why`，点明触发的是哪条腿及其数值（`破位因·上市以来年化` / `破位因·破24月线 近24月年化`）；**纯展示归因，不改判据、不进分数/排序/门禁**——取证显示按现标签排除「高分×破位」证据是反的
   - **NA 分口径与陈旧回退（决议 26）**：`长期—` 之后内联写明是 `取数失败` 还是 `数据不足`（两套关键词互斥，还没取到数时不猜原因）；成功条目写穿 `localStorage.dinvest_trend_cache`，重取失败时退回上次成功的数并内联 `截至 MM-DD·N 天前`（当天存的不标注，它本就是当日价口径）；`trendPick` 是唯一缓存裁决——失败/样本不足都不许擦掉已有标签；`dinvest_trend_fetch_stat` 按日记「这条请求成没成」，为第二步（东财断供时的备用源）攒实测数。**依旧纯展示，不进分数/排序/门禁**

## 8. 存储与前视验证

- 表 `stock_value`（批次制，RLS 只读 anon，与 `stock_score` 同构）：

```
code, name, ths_l1, ths_l2, batch_date,
vq, roic_cur, roic_med, roic_min3, fcf_yield, div_yield_5y, ep, bm, norm_yield,
net_cash, debt, gw_pct, owner_yield, margin_of_safety, cn10y, tier, vcov,
confidence, vetoed boolean, veto_reasons jsonb, flags jsonb,
main_final numeric,          -- 当晚 V1.1 主分快照（关键：复盘无需 join 历史批次）
main_confidence text,
swap_suggest_of code,        -- 若本行为持仓 Y 且存在更便宜的合格标的 X，记 X 的 code（§7.3）
extras jsonb                 -- 全部 GS 列日期戳 + ic_approx + 近似告警
UNIQUE(batch_date, code)
```

- **每晚把主分 final 一起快照**，否则半年后 join 会因主引擎改版而断裂
- **时点纪律（写死，约束将来一切回填）**：每个字段的 GS 日期戳原样落 `extras`；严禁用当期值回填历史基期（前视泄漏）；跨年比较只在相同报告期戳之间进行。P-4 已证明同一列的"历史版本"与"当期版本"无法共存于一次调用，故历史只能靠逐夜积累
- 前视读数：新脚本 `scripts/value_forward_check.ts`，季度用已有价格历史（腾讯 gtimg / 250 根 K 线）算 T+20/60/120 日收益，对"分歧榜两组"与"VQ 十分位 vs 主分十分位"做排序对比
- **判生死的时间表（诚实约束）**：至少积累 **2 个季度**才有初步读数，**6 个月**才有资格讨论是否接入主信号或调整阈值。在此之前任何"看起来更好"的权重改动都属无证据改动，一律拒绝
- **冷启动**：只跑当晚截面，不回填历史

## 9. 已知边界与 V2 空位

1. **投入资本近似**（§4.1）——本设计最大的一处已知的不精确，落地首周必须用三表接口校准
2. **cn10y 无现成批**——取数走 `gs-economy-query`，当日缓存；取不到则门禁退化为 `owner_yield ≥ 6%` 绝对下限，并记 `extras.rf_fallback=true`
3. **指数级 PE 历史分位**：GS 无口径（P-8），需自建每日价格 × 每日成分双序列；未来任何指数级判据必须走此路径，不得用当前成分回填历史
4. **真·逐年股息率序列**：受 P-7 限制，暂用 5 年平均
5. **审计非标**：P-5 返回全 None，待上游可用后补回硬否决位
6. **卖出侧基本不在本设计范围**：现有 `profitTiers` 止盈阶梯与本轮刚落地的横幅仲裁继续生效；价值腿只回答"该不该买/被错杀没有"，`too_rich` **永远不等于卖出**。唯一例外是 §7.3 的 `swap_suggest`——它只是展示行，不构成指令，也不改动上述任何一条既有规则
7. **权重 35/25/25/15 未经回测**——与 V1.0 决策"权重未经回测不得调整"同理，此权重是**前视验证的受试对象**，不是结论；§8 时间表届满前不得调

## 10. 测试方案

- **纯函数单测**（`value_engine_test.ts`，Deno，沿用现有风格）：
  `owner_yield` 取小保守性；`margin_of_safety` 门禁边界；`vcov<0.6` 不评分；三年 ROIC 缺期取现有期中位与"不足 2 期→NA"；四条硬否决逐条红/绿；金融股 ROIC 退化路径不误判否决；商誉空→0、股息率空→0 而 PE/PB 非正→NA 的**三种空值语义分别断言**；`main_final` 快照随行写入
- **数据层单测（P-3/P-4 教训固化）**：fixture 断言"请求了估值列但响应无该列 → 整批拒绝"；"历史窗口与三表科目混提 → 日期戳漂移必须被检出并置 NA"
- **黄金样本**：招商银行（金融股 NA 路径）、一家 `fcff` 连续两期为负 + 高带息债务的构造样本（否决）、一家 60 倍 PE 但行业内相对低的样本（**必须落 `too_rich`，用于证明百分位不能当门禁**——这是本设计两层结构的存在理由）
- **集成**：本地全量跑通后，看 VQ 分布与分歧榜 Top20 名单是否肉眼可解释；不可解释即停线上。**分布判据的统计口径（用户裁定③-2，2026-10-12）**：本条原写「VQ 分布（中位数应近 50）」默认了 VQ 覆盖全宇宙，与 §4–§5 的门禁设计相矛盾——VQ 只对 `qualified` 且 `vcov ≥ 0.6` 的行产出，门禁挡掉的那批根本不参与，合格者中位当然不是 50（首跑实测 88 只 qualified 的 `vq_median=77.8` 属选择效应，不是分布失真）。改为两句：**机制判据** = 全宇宙四维腿的百分位中位数应近 50（首跑实测 48.6 / 49.9 / 48.1 / 50.0 → 百分位机制健康）；**分布判据** = `vq is not null` 行内的 VQ 中位数与分位分布只如实报告、不设 50 目标（要设也只能设「明显高于全宇宙」，否则才说明门禁在挡错人）。**A 级占比 ≥40% 的分母改为非否决行 `tier <> 'vetoed'`（用户裁定，2026-10-12）**：全批口径与本节 §6 自相矛盾——5025 行里 2600 只（51.7%）是否决行，而 §6 明写否决行不得为 A，等于用一个规则把一半样本挡在门外再用总数去考另一个规则。v3 重跑（裁定① 的 flag 拆分已生效）实测：全批 1246/5025 = **24.8%**（该口径下红线不可达），非否决口径 1246/2425 = **51.4%** ✅。此后仍以非否决口径判 ≥40%，不达则停线上。
- **`swap_suggest` 单测**：5pp 换仓门槛边界（差 4.9pp 不给建议）；`rf_fallback` 且两侧口径不一致时该字段必须为 NULL；持仓侧与非持仓侧比较必须取**同批次** `margin_of_safety`
