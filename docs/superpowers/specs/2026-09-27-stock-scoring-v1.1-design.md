## 1. V1.1 文档与实现范围的边界（说破，避免日后误以为实现了完整 V1.1）

**采纳**（按层）：
- A 层（本计划必做）：低基数保护、PEG 低基数降权、Growth 封顶、利润现金含量入 Quality、毛利率恶化标记、动量拥挤度标记（新浪精确输入）、置信度分级、估值要求揭示（info-only）
- C 层（本计划必做）：混合业务识别（东财主营构成，按国标行业码拆分）+ 池降级全市场 + `mixed_business` 标记
- B 层（探针验证后定去留）：3年ROE中位数、3年营收CAGR、利润率恢复趋势、正常化PE

**明确不做**（V1.1 文档设想但无数据源或成本不可行）：
- **子业务级指标双池**（§3.2 完全体）：不存在提供"设备业务的ROE/材料业务的PE"的数据源。可实现版本是"公司级指标 + 池选择修正"，即 §5 的池降级规则。
- **EV/EBITDA**（§6）：需多表拼接利息/折旧/有息负债，GS 宽表不可靠，放弃。
- **订单/中标/剩余履约义务入模**（§8）：维持 V1.0 立场——定性信息不进量化模型，独立立项。
- **概念板块混合替代方案**：已被 C 层东财方案取代，作废。

## 2. 不变的约束（继承 V1.0）

- 四因子总权重 **Q30/G30/V20/M20 固定不动**（V1.1 §2 同意；未回测不得调整）；
- 风控/异常类信号**只标记不扣分**（V1.1 §9 反向证据机制与此一致）；
- 批次制 upsert、GS 失败不覆盖旧批次、NA 双层重归一——全部继承；
- 用户侧零操作：打开网页看结果，不引入 LLM key（V1.1 全部规则均为可计算判据，无定性理解需求）。

## 3. 数据通道矩阵

| 通道 | 角色 | 获取方式 | 失败降级 |
|---|---|---|---|
| GS 智能选股宽表 | 核心输入（唯一真源）：财务/估值/行情全池 | 现有 stock-score 内 2 次调用，扩列见 §4 | 现有守卫：不跑批不覆盖 |
| 新浪日K `CN_MarketDataService.getKLineData`（scale=240, datalen≤1023） | **仅增强层**：拥挤度 MA20/MA60；对账基准 | Edge Function 内 per-stock fetch，池内 ~1165 只 × 并发，约 5 分钟 | 缺失 → 拥挤度不出标记，评分不受影响 |
| 东财 F10 `PC_HSF10/BusinessAnalysis/PageAjax`（`zygcfx`, MAINOP_TYPE='1'） | C 层主营结构（半年才变，低频） | 新函数 `business-mix`，pg_cron 低频分批（见 §5.3） | 无当日数据 → 沿用 `stock_business_mix` 旧行 |
| 新浪/东财对账 | 保险：每晚抽 20 只比对 60 日涨幅，偏差 >2% 写 warnings | Edge Function 内 | 静默跳过 |

非官方接口声明：新浪/东财端点无文档无 SLA，因此**任何进入分数的核心输入仍只依赖 GS**；新浪失败不阻塞跑批，东财数据只影响标记与池选择（有半年缓存期）。

## 4. A 层规则详定

### 4.1 GS 宽表扩列（第 1 次调用追加指标）

- 经营现金流 / 净利润（TTNNJLRTBL 或同义指标）→ 现金含量
- 销售毛利率同比（毛利率较上期变化，百分点）→ 毛利率恶化标记
- 探针请求一并验证 B 层历史列：`净资产收益率 2023年报/2024年报/2025年报`、`营收同比增长率:单季度 近三年`（§8）

### 4.2 低基数保护（Growth）

**触发条件**：扣非净利润同比增长 > 200%（宽表仅有同比，上年绝对基数不可得——以 200% 单一阈值为可实现判据，记录此简化）。
**动作**：
1. `Growth 分位分 = min(原分, 85)`（封顶发生在因子百分位之后、综合加权重归一之前）；
2. flags 追加 `low_base_growth`；
3. **PEG 视为无效**（修复期增速算出的 PEG 是伪便宜，Value 退化为 PE 单腿 + renorm）——这是本增补对总分影响最大的修正。

**解除**：连续 2 个报告期不再触发（实现为窗口列对比，V1.1 语义内从简：当季不触发即解除，不做两期确认的状态机——记录此简化）。

### 4.3 利润现金含量入 Quality

Quality 内部权重调整为：**ROE 50 / 毛利率 35 / 现金含量 15**（A 层，缺列 NA→renorm，沿用金融股 mlr 剔除纪律——现金含量对金融股同样置 NA；毛利率由 50 降至 35 承接现金含量 15）。
现金含量百分位极端值缩尾：比值截断至 [-0.5, 2]（负现金流保留为低分，不剔除）。
B 层启用后再加入 3年ROE中位数，届时内部权重改为 **ROE 35 / 毛利率 25 / 现金含量 15 / ROE中位 25**（对齐 V1.1 文档 §4 的 40/20/25/15 精神，ROE 项差值归中位数；见 §8）。

### 4.4 毛利率恶化标记

触发：营收同比 ≥ 30% 且 毛利率同比 ≤ -5pp → flag `margin_deterioration`。不扣分、不封顶（V1.1 §9 列为反向证据，仅作标记）。

### 4.5 动量拥挤度标记（Momentum 不进分数）

数据：新浪日K → MA20、MA60、60日涨幅。
触发：60日涨幅处于同池 ≥95 分位 **且** 收盘价 > MA60 × 1.15 → flag `momentum_crowded`。不扣分。
新浪拉取失败的股票该标记缺省（不进入判定，不算触发）。

### 4.6 估值要求揭示（extras，info-only）

`implied_normal_pe` = 当前市值 ÷ 归母年化利润（H1 归母 × 2；非中报季用最近年报单期折算）。
输出到 `extras` 与持仓明细展开区，用于呈现"当前估值对未来盈利兑现的要求"（V1.1 §10 压力测试表的自动化版本）。不参与评分。

### 4.7 置信度分级（新增列 `confidence` CHAR(1)）

判定顺序（先命中先得）：
- **C**：行业样本不足（ind_n < 20 且已降级）或核心因子 ≥2 个为 null；
- **B**：任一 flag 命中（low_base_growth / mixed_business / margin_deterioration / momentum_crowded / 既有 warning 全部计入）或单因子缺失；
- **A**：其余。
Top10 卡片与持仓胶囊展示徽标；C 级不阻塞展示（我们无"不进严格排名"场景，池已限定，记录此差异）。

## 5. C 层：混合业务识别与池修正

### 5.1 判据（沿用 V1.1 §3.1，按国标行业码）

取最近报告期 `MAINOP_TYPE='1'` 各行业的收入占比：
- 最大行业占比 ≥ 70% → 单一主业，正常池；
- 最大 < 70% 且次大 ≥ 25% → **混合业务**：flag `mixed_business`，confidence 至多 B；
- 介于两者（如 62.4/37.6）→ flag `business_shift`，仍按现池评分（奥来德 2026H1 实测 62.4/28.4 即落此档+次大≥25 边缘，判据以 ≥25% 严格执行→混合）。

### 5.2 池修正（诚实的简化）

**不建"国标行业↔同花顺行业"映射表**（维护成本不可控）。混合业务个股的因子百分位改用**全市场宇宙**（双池加权在分布上趋近全市场，是错池的诚实替代），并在明细标注"全市场口径（混合业务）"。
单一主业但主营行业与 GS 现分类冲突（如注册地变更类噪声）→ 不处理，维持现池。

### 5.3 数据通道：新函数 `business-mix`

- 表 `stock_business_mix(code PK, report_date, segments JSONB, mixed BOOLEAN, updated_at)`；anon 只读；
- 触发：pg_cron **每年 5/9/11 月启动分批追赶**——每晚处理池内 1/4（~300 只，东财限速沿用 push2 备用域名经验），全量 1165 只四晚完成；
- stock-score nightly 读取该表（JOIN pool），表为空时 C 层整体静默跳过（评分退化为纯 A 层）；
- 新股入池时由 stock-score 顺带单只补拉（不等待批任务）。**〔实施修订 R7：不实现〕** 改由 business-mix 每晚按"最旧 updated_at（缺失优先）"轮转 300 只自然覆盖（新股 1–2 晚内入表）；避免 nightly 内嵌未测外部依赖。

## 6. 输出与前端

- `stock_score` DDL 增列：`confidence CHAR(1)`；flags/extras/warnings 沿用 JSONB 无需变更；
- Top10 卡片：名称后追加置信度徽标（A 绿/B 灰/C 橙）；`momentum_crowded`/`low_base_growth` 以角标呈现；
- 持仓明细展开区：四因子横条下追加"口径与置信度"行（全市场/行业池标注 + 置信度 + 混合业务收入结构一行文字，如"设备 62% / 材料 28%"）+ `implied_normal_pe` 揭示行；
- 无新增页面、无新交互——纯增量渲染，沿用 V1.0 降级纪律（无数据显示"—"）。

## 7. 验证标准

**对账断言（跑批后强制比对）**：
1. 奥来德 688378：Growth ≤ 85；PEG 不再进 Value（Value 单腿 PE）；flag 含 `low_base_growth`；置信度 = B；若 §5.1 判据执行正确，另含 `mixed_business` 且百分位为全市场口径；
2. 全体分布：触发低基数的股票数占比 **与 GS 原始列直算占比一致（±0.5pp）**〔实施修订 R8：原"<3%"阈值弃用〕——2026H1 处于业绩修复周期，扣非>200% 是数据现实而非规则误判；实测本批 low_base 396/5022 = **7.89%**，GS 原始列直算 406/5222 = 7.77%，差 +0.12pp 落在 ±0.5pp 内 ✓。维持 kc>200 阈值与封顶 85（温和惩罚）。A/B/C 置信度比例记录基线（本批 A=3056 / B=1966 / C=0）；
3. 既有持仓回归：潍柴 M<35、招行 Q 高位等 V1.0 断言全部保持（A 层规则不应触碰它们）；
4. 排序合理性抽检（§3 讨论的机制修正）：修复后 Top20 中不得出现"仅凭扣非增速>200% 进入"而 3 年轨迹缺失的公司——B 层上线前此项为软标准。

**回测**：本机仍无历史管道，维持 V1.0 spec §22 立场；每晚批次积累即为未来回测数据。

## 8. B 层探针与去留

探针（一次性，实现前执行）：GS 全池查询措辞追加 3 个年报期 ROE 窗口列 + 3年营收CAGR，验证：① 返回列存在；② 非空率 >80%；③ 奥来德抽样值 ≈ 7.20/5.15/4.22。
- **通过** → 实施：Quality 加 3年ROE中位数（权重见 §4.3）；Growth 重构为 营收同比 30 / 扣非同比 25 / 营收CAGR 20 / 归母同比 10 / **利润率恢复代理 15**（= 毛利率 2026H1 − 2025A，文档"3年盈利恢复"的可用代理，记录此近似）；Value 加正常化PE（= 市值 ÷ 3年扣非中位数，数据不足→NA）；
- **不通过** → B 层整体放弃，A+C 即为本版终态，Growth/Quality 维持 §4 结构，无沉没成本（探针请求不进生产代码）。

## 9. 与 V1.1 文档的已记录裁决（Rulings）

| # | 裁决 | 理由 | 代价 |
|---|---|---|---|
| R1 | 低基数判据用">200%"单条件，不查上年绝对基数 | 宽表无上年值 | 极少数高基数真爆发被误封顶（85 分仍高） |
| R2 | 封顶解除不做两期状态机 | 窗口列历史对比成本 | 修复后首期即解禁，略宽松 |
| R3 | 混合业务用池降级全市场，不做子指标双池 | 无子业务指标数据源 | 失去行业中性化，文档 §3.2 完全体未实现 |
| R4 | 不做国标↔同花顺映射表 | 维护成本 | 混合判定粒度停留在国标行业，与评分池体系并行存在 |
| R5 | C 级不"退出严格排名" | 我们无此场景 | 与文档 §10 语义偏差，仅展示层 |
| R6 | B 层"利润率恢复"用毛利率差值代理 | 无3年利润序列保证 | 项目型公司季节性可能污染该代理 |
| R7 | 新股单只补拉不实现，改每晚最旧轮转自然覆盖 | 不在 nightly 内嵌未测外部依赖 | 新股入池后 1–2 晚才获 C 层标注，期间走行业池口径 |
| R8 | low_base 阈值维持 kc>200，§7.2 断言从"<3%"改为"与 GS 原始列占比一致(±0.5pp)" | 2026H1 修复周期扣非>200% 普遍，非规则误判 | 若未来某期低基数暴涨数异常多，封顶 85 会温和压分而非精确识别 |
